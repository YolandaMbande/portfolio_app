Unsaid — Say it out loud.

Unsaid is an AI-powered conversational companion designed to give users a private space to express and unpack their thoughts. Built with Laravel, PHP, JavaScript and PostgreSQL, the application features AI-powered conversations, secure user accounts, private and persistent chat histories, voice-to-text interaction, text-to-speech responses, and a dedicated Call Mode for more natural voice conversations.
