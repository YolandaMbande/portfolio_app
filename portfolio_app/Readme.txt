# Personal Portfolio

![Portfolio Preview](assets/readme_preview.gif)

A personal portfolio website showcasing my background, skills, projects, experience, and contact information as a software developer.

## About

This portfolio was created to provide a central place to showcase my software development work, projects, technical skills, and experience.

The website includes dedicated sections for:

* About Me
* Resume
* Services
* Portfolio Projects
* Project Details
* Contact

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YolandaMbande/portfolio_app.git
```

Navigate into the project:

```bash
cd portfolio_app
```

If the project uses npm dependencies:

```bash
npm install
```

Then open the project in your browser or run it using your preferred local development environment.
